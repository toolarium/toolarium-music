# Finale test samples

Source: [eNote-GmbH/scorewriter-comparison](https://github.com/eNote-GmbH/scorewriter-comparison)
repository on the `main` branch, `Finale/` directory, downloaded on 2026-11-14.

License: CC BY 4.0. These files are used only as test input and are not part of the toolarium
library itself. Attribution: eNote GmbH.

Each file is a small, feature-specific Finale `.musx` score created for comparing MusicXML export
capabilities across different scorewriters. The 13 files cover: arpeggios and glissandi,
articulations, barlines, colour, dynamics (above and below), fermatas, key signatures, ornaments,
repeats, rest positions, text styles, and time signatures.
