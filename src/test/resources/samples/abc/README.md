# ABC test samples

Created for this project no third-party content.

| File | Content |
|------|---------|
| `features.abc` | Header fields, key, tempo, pickup, ties, broken rhythm, triplet, chord, grace note, decorations, endings, parts, rests, multi-measure rest, lyrics and a meter change |
| `voices.abc` | Two voices joined into one piano part with two staves (`%%score {RH LH}`) |
| `jig.abc` | Jig in 6/8 with anacrusis, repeats, chord symbols and first and second endings |
| `song.abc` | Song in 3/4 with two lyrics verses, hyphens and an extension line |
| `modes.abc` | Key changes in the tune in all spellings (`K:Cmajor`, `K:C maj`, `K:A minor`, `K:Am`) and all church modes (Ionian, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian), clef option of `K:` (`bass`, `treble`) |
| `notation.abc` | Comments after header fields and in the tune, fields `O:`, `S:`, `N:`, `R:` and `W:` (words after the tune), meter C, changes of the unit note length (1/16, 1/8, 1/4), double sharp and double flat, tuplets `(2`, `(4`, `(5`, `(6`, `(7` and `(3:2:3`, barlines `[\|`, `\|\|`, `::` and `\|]`, annotation `"^..."` |
| `transposing.abc` | Transposing instrument (`%%MIDI transpose`), `%%writefields`, chord symbols in a hidden second voice (`%%staves`, `V:`, invisible rests `x`) |
